## 一个仿射体的状态

<MathBridge>
  <li>先用 `A @ x_rest` 改变点相对物体中心的方向和长度。</li>
  <li>再用 `+ t` 把整个变形后的物体搬到世界位置。</li>
  <li>最后把 `A` 的 9 个数和 `t` 的 3 个数排成求解器读得懂的 `q`。</li>
</MathBridge>

对一个静止点 `x_rest`，仿射体把它放到世界空间：`x_world = A @ x_rest + t`。这里 `A` 是 3x3 矩阵，负责旋转、拉伸、缩放和剪切；`t` 是 3D 向量，负责整体平移。

<ConceptCard title="A 管形状方向，t 管整体位置">
把物体想成一张贴纸。`A` 决定贴纸是否被转动、拉长或斜着压；`t` 决定整张贴纸贴在桌面上的哪个位置。两者合起来才得到世界空间中的点。
</ConceptCard>

<PseudoCode title="点映射与 q 打包">
{`def affine_point(A, t, x_rest):
    return A @ x_rest + t

def pack_q(A, t):
    return [A[0,0], A[1,0], A[2,0], A[0,1], A[1,1], A[2,1], A[0,2], A[1,2], A[2,2], t[0], t[1], t[2]]`}
</PseudoCode>

这个 `pack_q` 使用按列打包的方式：先放 `A` 的第一列，再放第二列、第三列，最后放平移 `t`。所以一个仿射体的广义坐标是 9 个矩阵数字加 3 个平移数字，总共 12 个数字。

<CompareGrid title="状态拆开看">
  <article><h4>`A`</h4><p>3x3，共 9 个数字，描述局部基方向如何变到世界空间。</p></article>
  <article><h4>`t`</h4><p>3 个数字，描述物体参考点或整体位置的世界平移。</p></article>
  <article><h4>`q in R12`</h4><p>把 `A` 和 `t` 线性排成一个 12 维数组，便于求解器处理。</p></article>
</CompareGrid>

<StepFlow title="从静止点到世界点">
  <li>取物体局部坐标里的点 `x_rest`。</li>
  <li>用 `A` 改变它相对物体的方向和长度。</li>
  <li>加上 `t`，把结果搬到世界位置。</li>
  <li>对物体上的所有采样点重复同一个映射。</li>
</StepFlow>

<PitfallCard title="q 不是 12 个互不相关的旋钮">
虽然 `q` 是一个 12 维数组，但前 9 个数字组成同一个矩阵 `A`。改变其中一个数字会改变整个物体的一个方向分量，而不是只移动某个单独顶点。
</PitfallCard>

<CheckpointQuiz>
  <details>
    <summary>`t` 能表达剪切吗？</summary>
    <p>不能。`t` 只把整个物体平移到新的世界位置；剪切属于线性变换，需要由 `A` 的列方向和分量来表达。</p>
  </details>
  <details>
    <summary>`A` 和 `t` 为什么能打包成 12 个数？</summary>
    <p>`A` 是 3x3 矩阵，有 9 个数字；`t` 是 3D 平移向量，有 3 个数字。按固定顺序排成数组后，求解器就能把它们当作一个 12 维广义坐标处理。</p>
  </details>
</CheckpointQuiz>

<WorkedExercise title="带答案的练习：打包一个拉伸状态">
给定 `A = diag(2, 1, 1)` 和 `t = [3, 0, 0]`。请按本页的列优先顺序把它们打包成 `q`，再说明静止点 `x_rest = [1, 0, 0]` 会被送到哪里。

<details>
  <summary>提示</summary>
  <p>`diag(2, 1, 1)` 的三列分别是 `[2, 0, 0]`、`[0, 1, 0]`、`[0, 0, 1]`。先写完三列，再接上 `t`。</p>
</details>

<details>
  <summary>参考答案</summary>
  <p>按列优先打包时，`q = [2, 0, 0, 0, 1, 0, 0, 0, 1, 3, 0, 0]`。对静止点 `x_rest = [1, 0, 0]`，先算 `A @ x_rest = [2, 0, 0]`，表示它在局部 x 方向被拉到原来的 2 倍；再加 `t = [3, 0, 0]`，得到世界位置 `[5, 0, 0]`。</p>
</details>
</WorkedExercise>
