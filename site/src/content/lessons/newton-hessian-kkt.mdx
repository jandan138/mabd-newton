## 残差就是“还差多少”

如果目标是找到 `x` 使 `r(x) = 0`，那么 `r` 就是残差。Newton 方法在当前猜测 `x_k` 附近用 Jacobian `J = partial r / partial x` 做线性近似：`r(x_k + dx) approx r(x_k) + J dx`。令近似残差为零，就得到修正方程 `J dx = -r`。

<ConceptCard title="Newton 像在山坡上校准地图">
你站在弯曲山坡上，想找海拔为零的点。Newton 不知道整座山的形状，只看脚下坡度，画一张局部直线地图，然后走一步。走完再重新量坡度，直到高度残差足够小。
</ConceptCard>

<StepFlow title="Newton 迭代">
  <li>给未知量一个初始猜测。</li>
  <li>计算残差 `r`，判断还差多少。</li>
  <li>计算 Jacobian 或由能量二阶导得到 Hessian。</li>
  <li>解线性系统得到增量 `dx`，更新未知量。</li>
  <li>重复直到残差或增量足够小。</li>
</StepFlow>

<PseudoCode title="Newton 残差求解">
{`x = initial_guess
for iter in range(max_iters):
    r = residual(x)
    if norm(r) < tolerance:
        break
    J = jacobian(residual, x)
    dx = solve(J, -r)
    x = x + dx`}
</PseudoCode>

## Hessian 与约束

当方程来自能量最小化时，一阶导数是梯度，二阶导数是 Hessian。Hessian 可以理解为局部曲率，也常对应刚度矩阵：曲率越大，系统越抗拒某个方向的变化。

约束会额外要求 `C(q) = 0`，例如两个关节点必须重合。拉格朗日乘子 `lambda` 是和约束一起求出的对偶变量：它不直接描述位置；只有结合约束写法、离散化尺度和 `G.T lambda`，才可能解释成约束反馈到运动方程的作用。

<ConceptCard title="KKT 是同一张谈判桌">
KKT 系统像把“物体想怎么动”和“约束不允许怎么动”放到同一张谈判桌。左上角的块描述运动或刚度，右上和左下的约束 Jacobian 描述规则，`lambda` 则是规则对应的约束对偶变量。
</ConceptCard>

<PseudoCode title="典型 KKT 块结构">
{`# Unknowns: motion increment dq and Lagrange multipliers lambda
# H: Hessian or effective system matrix
# G: constraint Jacobian
# g: motion residual
# c: constraint residual

[ H   G.T ] [ dq     ] = [ -g ]
[ G    0  ] [ lambda ]   [ -c ]`}
</PseudoCode>

<CompareGrid title="三个矩阵角色">
  <article><h4>Jacobian</h4><p>一阶变化率：输入变一点，残差或约束怎么变。</p></article>
  <article><h4>Hessian</h4><p>二阶曲率：能量局部像多硬的碗。</p></article>
  <article><h4>KKT 矩阵</h4><p>把运动未知量和约束乘子合并求解。</p></article>
</CompareGrid>

<PitfallCard title="KKT 的 lambda 不是随手添加的修正量">
`lambda` 是和约束方程一起求出的对偶变量。它的符号、单位和物理解释依赖约束写法；只看数值大小而不看约束 Jacobian，容易误读约束力。
</PitfallCard>

<CheckpointQuiz>
  <details>
    <summary>为什么 KKT 要同时求 `dq` 和 `lambda`？</summary>
    <p>`dq` 修正运动未知量，`lambda` 给出约束为了成立所需的对偶变量。二者耦合在同一个线性化系统里，才能同时让运动方程和约束方程趋向满足。</p>
  </details>
  <details>
    <summary>`H` 和 `G` 分别来自哪里？</summary>
    <p>`H` 通常来自能量、惯性或残差线性化后的运动块；`G` 来自约束 `C(q)` 对广义坐标的 Jacobian，描述状态变化会怎样改变约束残差。</p>
  </details>
</CheckpointQuiz>

<WorkedExercise title="带答案的练习：标注 pinned point KKT">
  <p>把一个 pinned point 的两行块系统写成 `[H G.T; G 0][dq; lambda]=[-g; -c]`，并标出哪一块来自运动修正、哪一块来自约束、未知量分别是什么。</p>
  <details>
    <summary>提示</summary>
    <p>先看左上角和左下角：左上角只作用在 `dq` 上，左下角把 `dq` 映射成 pinned point 约束残差变化。</p>
  </details>
  <details>
    <summary>参考答案</summary>
    <p>`H` 是运动方程的 Hessian 或有效系统矩阵，乘以 motion correction `dq`；`G` 是 pinned point 约束对 `q` 的 Jacobian，`G dq` 表示这次修正会怎样改变被钉住点的约束残差；`G.T lambda` 是约束变量反馈到运动方程的项；`lambda` 是约束对偶变量。两行分别是 `H dq + G.T lambda = -g` 和 `G dq = -c`，表示运动修正和约束变量被耦合求解，而不是分两步补丁。</p>
  </details>
</WorkedExercise>

<MisconceptionRepair title="误解纠正：lambda 不是可直接横向比较的约束力">
  <dl>
    <dt>误解</dt>
    <dd>“`lambda` 就是可以直接比较大小的约束力。”</dd>
    <dt>为什么容易这样想</dt>
    <dd>KKT 方程把 `lambda` 放在运动方程旁边，看起来像求解器直接输出了力。</dd>
    <dt>正确读法</dt>
    <dd>`lambda` 是约束对偶变量；只有结合约束 Jacobian、时间离散、尺度和单位，才可能解释它反馈到运动方程中的作用。</dd>
    <dt>下一步检查</dt>
    <dd>先看 `G.T lambda` 如何进入残差，再查记录是否说明了该约束写法和尺度。</dd>
  </dl>
