## 向量：箭头，也是数字列表

一个 2D 向量 `[3, 1]` 可以看成从原点指向右 3、上 1 的箭头，也可以看成程序里的两个数字。物理直觉喜欢箭头，代码喜欢数组；两种看法说的是同一个对象。

<ConceptCard title="矩阵是变换机器">
矩阵接收一个向量，输出另一个向量。旋转矩阵让箭头转向，缩放矩阵让箭头变长或变短，剪切矩阵让方格变斜。ABD 中的 3x3 矩阵 `A` 就是一台可以同时做这些事的机器。
</ConceptCard>

## 先看 2D，再看 3D

2D 里，一个矩阵有两列。第一列告诉你单位 x 方向会被送到哪里，第二列告诉你单位 y 方向会被送到哪里。

<MathBridge>
  <li>先只看一个点：`[1, 0]` 被矩阵送到第一列。</li>
  <li>再看两个基方向：第一列和第二列一起决定方格如何倾斜或拉伸。</li>
  <li>最后把同一规则搬到 3D：三列分别控制局部 x、y、z 方向。</li>
</MathBridge>

<HandCalc title="手算小算例：剪切矩阵把基箭头送到哪里">
  <p>给定 `A = [[1, 0.5], [0, 1]]`。</p>
  <table>
    <thead><tr><th>输入</th><th>计算</th><th>结果</th><th>解释</th></tr></thead>
    <tbody>
      <tr><td>`e_x = [1, 0]`</td><td>`A @ e_x`</td><td>`[1, 0]`</td><td>x 方向不变。</td></tr>
      <tr><td>`e_y = [0, 1]`</td><td>`A @ e_y`</td><td>`[0.5, 1]`</td><td>y 方向向右偏，方格被剪切。</td></tr>
    </tbody>
  </table>
</HandCalc>

<PseudoCode title="2D 基向量列">
{`A = [[2, 0],
     [0, 1]]

e_x = [1, 0]
e_y = [0, 1]

A @ e_x  # -> [2, 0], x 方向被拉长
A @ e_y  # -> [0, 1], y 方向不变`}
</PseudoCode>

到了 3D，矩阵变成 3x3，有三列，分别描述物体局部 x、y、z 三个基方向在世界空间中的样子。ABD 频繁出现 3x3 矩阵，是因为三维物体的线性变换需要同时管理三个方向。

<CompareGrid title="几个常见直觉">
  <article><h4>基列</h4><p>矩阵的列像新坐标轴。看列向量能直接看出方块被拉向哪里。</p></article>
  <article><h4>转置</h4><p>对旋转矩阵，转置像把世界方向投回局部坐标；它也常出现在内积和 Jacobian 转换中。</p></article>
  <article><h4>逆矩阵</h4><p>逆矩阵像“撤销机器”。先用 A 变换，再用 A 的逆变回去。</p></article>
  <article><h4>3x3 矩阵</h4><p>在 3D ABD 中，`A` 同时编码旋转、缩放和剪切，因此自然是 3x3。</p></article>
</CompareGrid>

<StepFlow title="读矩阵公式的顺序">
  <li>先问输入向量是什么坐标系里的量。</li>
  <li>再看矩阵的列：它把局部基方向送到哪里。</li>
  <li>最后看输出向量要给谁用，是世界位置、局部方向，还是力映射。</li>
</StepFlow>

<PitfallCard title="不要只背乘法规则">
矩阵乘法的行列规则很重要，但只背规则会丢掉几何意义。读 ABD 公式时，优先问“这个乘法把哪个空间里的箭头变到哪个空间”。
</PitfallCard>

<CheckpointQuiz>
  <details>
    <summary>为什么矩阵的列可以像基向量一样读？</summary>
    <p>因为矩阵乘以单位 x、y、z 方向时，输出正好是对应列。每一列都告诉你原来的一个基方向被送到了哪里。</p>
  </details>
  <details>
    <summary>`x_prime = A @ x` 在代码里至少需要哪些输入？</summary>
    <p>需要矩阵 `A`、输入向量 `x`，以及两者一致的维度约定。程序还要知道它们代表哪个坐标系中的量，才能正确解释输出 `x_prime`。</p>
  </details>
</CheckpointQuiz>

<WorkedExercise title="带答案的练习：读懂剪切矩阵">
把剪切矩阵 `[[1, 0.5], [0, 1]]` 分别作用到 `[1, 0]` 和 `[0, 1]`。写出两个结果，并用一句话描述印章上方格的变化。

<details>
  <summary>提示</summary>
  <p>矩阵乘以 `[1, 0]` 会取出第一列；矩阵乘以 `[0, 1]` 会取出第二列。</p>
</details>

<details>
  <summary>参考答案</summary>
  <p>`[[1, 0.5], [0, 1]] @ [1, 0] = [1, 0]`，所以局部 x 方向保持不变。`[[1, 0.5], [0, 1]] @ [0, 1] = [0.5, 1]`，所以局部 y 方向向右倾斜 0.5 个单位。方格不会整体放大成更大的正方形，而是被剪切成向右倾斜的平行四边形网格。</p>
</details>
</WorkedExercise>

<MisconceptionRepair title="常见误解纠正">
<dl>
  <dt>误解</dt>
  <dd>矩阵只是数字表，列没有几何含义。</dd>
  <dt>为什么容易这样想</dt>
  <dd>编程时矩阵经常以二维数组出现，视觉上确实像普通表格。</dd>
  <dt>正确读法</dt>
  <dd>矩阵的每一列说明一个局部基方向会被送到哪里；列一起定义了方格如何变形。</dd>
  <dt>下一步检查</dt>
  <dd>看到 `A @ x` 时，先用单位基向量试算每一列，再解释输出方向。</dd>
</dl>
</MisconceptionRepair>
