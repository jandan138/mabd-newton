## 从点到旋钮

<MathBridge>
  <li>先写点位置 `x(q)`：标记点的位置由印章的状态旋钮决定。</li>
  <li>再线性化得到 `dx = J dq`：旋钮小动一下，点跟着小动。</li>
  <li>最后用虚功反向读力：点力通过 `J^T f` 变成广义力。</li>
</MathBridge>

`q` 是广义坐标，可以理解为控制物体的旋钮；`qd` 是这些旋钮的速度。一个点的位置 `x(q)` 由旋钮决定，所以点的小变化满足 `dx = J dq`，这里的 `J = partial x / partial q` 就是 Jacobian。

<ConceptCard title="手推点，旋钮受力">
物理力像一只手推世界空间中的某个点。广义力不是另一只手，而是这个推力对控制旋钮产生的效果：哪个旋钮会被推动、推动多少、方向是什么。`J^T f` 就是在回答“这只手的推力应该分摊到哪些旋钮上”。
</ConceptCard>

<StepFlow title="力映射的四步">
  <li>写出点位置函数 `x(q)`。</li>
  <li>求 Jacobian：`J = partial x / partial q`。</li>
  <li>用虚功相等：`f dot dx = tau dot dq`。</li>
  <li>代入 `dx = J dq`，得到广义力 `tau = J^T f`。</li>
</StepFlow>

## 虚功为什么有用

虚功可以理解成“很小、想象中的位移做了多少功”。如果点受到力 `f`，点移动 `dx` 的功是 `f dot dx`。同一件事从广义坐标看，是广义力 `tau` 推动旋钮变化 `dq`，功是 `tau dot dq`。两边必须相同，才不会凭空多出或少掉能量记账。

<PseudoCode title="把点力映射到广义力">
{`# x(q): point position controlled by generalized coordinates
# f: physical force on that point
J = jacobian(x, q)
tau = transpose(J) @ f

# qd maps to point velocity in the opposite direction
xd = J @ qd`}
</PseudoCode>

<CompareGrid title="两种视角">
  <article><h4>物理空间</h4><p>看见的是点、方向和牛顿力，例如某个角点被向右推。</p></article>
  <article><h4>广义坐标空间</h4><p>看见的是 `q` 的每个分量该增加还是减少，以及变化强度。</p></article>
  <article><h4>Jacobian</h4><p>像翻译器：`J qd` 把旋钮速度翻译成点速度，`J^T f` 把点力翻译成旋钮力。</p></article>
</CompareGrid>

<PitfallCard title="J^T f 不是随便转置一下">
转置来自虚功守恒，不是记忆技巧。如果 `J` 描述“旋钮怎么移动点”，那么 `J^T` 描述“点上的力如何反馈到旋钮”。形状和单位对不上时，通常说明点位置函数或坐标打包顺序没理清。
</PitfallCard>

<CheckpointQuiz>
  <details>
    <summary>`J qd` 和 `J^T f` 的方向为什么相反？</summary>
    <p>`J qd` 从广义速度推到点速度；`J^T f` 从点力拉回到广义力。两者方向相反，但通过虚功 `f dot dx = tau dot dq` 保持同一件物理作用的功一致。</p>
  </details>
  <details>
    <summary>为什么点力不能直接加到 `q` 上？</summary>
    <p>点力生活在世界空间，而 `q` 的分量可能是平移、旋转或仿射矩阵条目。必须先用 Jacobian 转换，才能知道这个点力会推动哪些广义坐标。</p>
  </details>
</CheckpointQuiz>

<WorkedExercise title="带答案的练习：速度映射和力映射的方向">
给定印章上的一个标记点和施加在该点的世界空间力 `f`。请说明 `J qd` 和 `J^T f` 各自从哪个空间映射到哪个空间，输出分别代表什么。

<details>
  <summary>提示</summary>
  <p>`J` 来自点位置 `x(q)` 对广义坐标的导数，所以它先回答“`q` 的速度会让点怎么动”。力的方向用虚功关系反过来读。</p>
</details>

<details>
  <summary>参考答案</summary>
  <p>`J qd` 的方向是从广义速度空间到点速度空间：输入是印章状态旋钮的速度 `qd`，输出是这个标记点在世界空间中的速度 `xd`。`J^T f` 的方向是从点力空间到广义力空间：输入是作用在标记点上的世界空间力 `f`，输出是对 `q` 每个分量的广义力 `tau`，表示这股点力会推动哪些平移、旋转或仿射分量。两者通过虚功 `f dot (J dq) = (J^T f) dot dq` 保持同一物理作用的功一致。</p>
</details>
</WorkedExercise>
