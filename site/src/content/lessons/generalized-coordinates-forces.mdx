## 从点到旋钮

`q` 是广义坐标，可以理解为控制物体的旋钮；`qd` 是这些旋钮的速度。一个点的位置 `x(q)` 由旋钮决定，所以点的小变化满足 `dx = J dq`，这里的 `J = partial x / partial q` 就是 Jacobian。

<ConceptCard title="手推点，旋钮受力">
物理力像一只手推世界空间中的某个点。广义力不是另一只手，而是这个推力对控制旋钮产生的效果：哪个旋钮会被推动、推动多少、方向是什么。`J^T f` 就是在回答“这只手的推力应该分摊到哪些旋钮上”。
</ConceptCard>

<StepFlow title="力映射的四步">
  <li>写出点位置函数 `x(q)`。</li>
  <li>求 Jacobian：`J = partial x / partial q`。</li>
  <li>用虚功相等：`f dot dx = tau dot dq`。</li>
  <li>代入 `dx = J dq`，得到广义力 `tau = J^T f`。</li>
</StepFlow>

## 虚功为什么有用

虚功可以理解成“很小、想象中的位移做了多少功”。如果点受到力 `f`，点移动 `dx` 的功是 `f dot dx`。同一件事从广义坐标看，是广义力 `tau` 推动旋钮变化 `dq`，功是 `tau dot dq`。两边必须相同，才不会凭空多出或少掉能量记账。

<PseudoCode title="把点力映射到广义力">
{`# x(q): point position controlled by generalized coordinates
# f: physical force on that point
J = jacobian(x, q)
tau = transpose(J) @ f

# qd maps to point velocity in the opposite direction
xd = J @ qd`}
</PseudoCode>

</CompareGrid>

<PitfallCard title="J^T f 不是随便转置一下">
转置来自虚功守恒，不是记忆技巧。如果 `J` 描述“旋钮怎么移动点”，那么 `J^T` 描述“点上的力如何反馈到旋钮”。形状和单位对不上时，通常说明点位置函数或坐标打包顺序没理清。
</PitfallCard>
