## Scope

Phase 71 adds a bounded affine box vs static infinite plane active-set
detector inside vendored/local Newton:
`SolverMABD.detect_static_plane_contacts`. The detector emits
`newton.Contacts` rows from M-ABD affine box corners against static infinite planes
and records `last_static_plane_collision_summary`.

The report lane is configured by
`paper_horizon.affine_static_plane_contacts_output_report` and exposed through
`run_spinning_box_affine_static_plane_contacts` / CLI lane
`spinning_box_affine_static_plane_contacts`. The report writer is
`write_spinning_box_affine_static_plane_contacts_report`; its helper is
`_run_spinning_box_solver_mabd_affine_static_plane_contacts_step`.

The helper calls `SolverMABD.detect_static_plane_contacts` and then
`SolverMABD.step(..., contacts=...)`. It records
`last_contacts_input_summary` through the same bounded contacts-input path as
Phase 69 and Phase 70. Report-layer code does not synthesize the active set.
